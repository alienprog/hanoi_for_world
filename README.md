# Ханойские башни

Версия для GitHub Pages. Работает на HTML, CSS и JavaScript, без backend, базы данных и регистрации.

## Публикация

1. Создать репозиторий на GitHub или выбрать отдельную ветку существующего.
2. Загрузить содержимое этой папки в корень репозитория. `index.html`, `.nojekyll` и папка `frontend` должны быть на одном уровне.
3. Открыть Settings > Pages.
4. В Source выбрать Deploy from a branch.
5. Выбрать ветку с файлами сайта и папку /(root), нажать Save.
6. Дождаться завершения публикации. Ссылка появится в разделе Pages.

Сборка и установка зависимостей не нужны. Пути к файлам относительные, поэтому сайт работает и в подпапке репозитория.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Возможности

- 12 уровней с последовательным открытием. Пройденные выделены зелёным.
- Своя и случайная игра: 3-8 дисков, 3-5 стержней.
- Управление мышью, касанием и клавиатурой.
- Перезапуск, подсчёт ходов и определение победы.
- Профиль со сменой аватара.
- Сохранение партии и прогресса в браузере.

Tab / Shift+Tab выбирают стержень, ↑ поднимает диск, ← / → перемещают, ↓ опускает. Escape отменяет перенос. Полное управление находится в справке по кнопке ⓘ.

Данные сохраняются только в текущем браузере. Очистка данных сайта удаляет прогресс. Между устройствами и адресами сайта сохранения не переносятся.

## Файлы

- `index.html` - главная страница.
- `frontend/game.js`, `game.css` - ядро и игровое поле.
- `frontend/app.js`, `app.css` - меню, экраны и профиль.
- `frontend/session.js` - локальное сохранение.
- `frontend/levels.json` - параметры уровней.
- `.nojekyll` - публикация готовых файлов без Jekyll.

## Локальный просмотр

Для просмотра можно использовать Live Server в редакторе. Если установлен Python, из этой папки:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Открыть http://localhost:8080. Это только раздача файлов для просмотра; приложение не обращается к серверному API. Для опубликованного сайта Python не нужен. Двойной щелчок по HTML не подходит: каталог уровней загружается по HTTP.
